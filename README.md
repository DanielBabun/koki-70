# Plantilla: invitación koki (70 años, tema japonés)

Para reusarla con otra persona o lugar:

1. Textos: editar `invitacion.html` (nombre, fecha, hora, lugar, programa, teléfono en `EVENTO`).
2. Fotos (mismo nombre de archivo, se reemplazan y listo):
   - `fotos/keiko.jpg` foto de la homenajeada (vertical 4:5)
   - `fotos/lugar.jpg` foto del lugar (vertical 4:5)
   - `fotos/grullas.jpg`, `fotos/te.jpg`, `fotos/jardin.jpg` sección Tradición
3. Armar la página: `cd ~/Developer && python3 armar-pagina.py cumple-koki <url> "<título>" "<descripción>" "#5B3A78"`
4. Vista previa de WhatsApp: `vista.jpg` (1200×630).

Fotos de ejemplo: Unsplash (licencia libre). Lugar de ejemplo: Sushi Itto Altara, C. C. Altara, San Pedro Sula.
